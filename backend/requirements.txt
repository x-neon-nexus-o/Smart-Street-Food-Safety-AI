# Local translation (Phase 6) -- replaces Google Cloud Translation.
# No API key, no quota, no billing; label text never leaves the machine.
#
# transformers is pinned EXACTLY, deliberately, and this is the one pin in
# this file that must not be "helpfully" bumped. The model's remote code reads
# `past_key_values[0][0]`, i.e. the legacy *tuple* KV cache. Newer versions
# hand it a Cache object and every translation dies with
#   AttributeError: 'NoneType' object has no attribute 'shape'
# Measured, one probe per version: 4.51.3 is the newest that works; 4.55.4
# fails with "Cache only has 0 layers", 4.56.2+ with the AttributeError above,
# and 4.44.2 has no installable tokenizers for cp314 (pip falls back to
# compiling Rust, which fails). A working KV cache is worth 2.2x on a normal
# sentence and 3.3x on a long one. See app/integrations/indictrans2.py.
